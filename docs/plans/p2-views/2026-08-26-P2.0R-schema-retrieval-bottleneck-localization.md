## 2. 事先写死的假设（预测在前）

### P0 · 设施自检：现役 `schema_search` 的字段级 Top-5 = **0%**

理由见 §1.2：它不返回字段，且英文子串匹配对中文问句零命中。
⇒ **若不为 0，说明我读错了实现，停下重读，本轮全部结论作废。**

### P1 · 复现 Spike 07「业务全量 + 人话描述」：Top-5 落在 **45%–70%**（XM 同档 60%）

### P2 · 复现 Spike 07「有数据 + 人话描述」：Top-5 落在 **60%–85%**，且**必然 ≤ 87.5%**（§1.5）

### P3 · 失败方式：miss 里「字段名对、DocType 错」的占比 **≥ 50%**

判法事先写死：一条 miss 若其 Top-5 中存在某项，其**字段名（`fieldname`）与某个
`expected` 的字段名相同、而 DocType 不同**，即计入「单据错」。

### P4 · 🔴 决定性一格 · oracle 消融：**把 ground-truth DocType 直接给定**，只在该 DocType 的字段内检索 → Top-5 **≥ 90%**

这一格把「选单据」和「选字段」**切开单独量**。

### 判定标准（同样事先写死）

| 组合 | 判定 | 下一轮做什么 |
|---|---|---|
| P0 ✅ 且 **P4 ✅** | **瓶颈在选单据，不在选字段** | 主攻 **DocType 消歧**；roadmap 候选方向里「结构化召回」优先，**换更好的 embedding 不是解法** |
| P0 ✅ 且 **P4 ❌** | 字段级检索本身也不够 | **不得选路**（D-16），重新设计实验 |
| **P0 ❌** | 设施有问题 | 全部作废，重做 |

⚠️ **P1/P2/P3 不参与选路判定**，它们只用来确认「本站点上的复现与 XM 同形」。
若 P1/P2 落在区间外，**照实记，不改预测**，并把「与 XM 不同形」本身作为一条结论。

⚠️ **本轮明确不宣称达到 90%。** 90% 是 P2.0R 的验收线，本轮只交「瓶颈在哪」。

### 12.3 P3 没中，照实记，不改预测

我事先写死的判法过窄：要求 Top-5 里存在一项**字段名（`fieldname`）完全相同**而 DocType 不同。
实际的错法多是**语义邻近但字段名不同**（`actual_qty` / `stock_qty` / `packed_qty` 互串），

**换一个事后（post-hoc，明确标注不是事先写死的）口径**：一条 miss 里，**正确的 DocType
有没有在 Top-5 里出现过**——

| 档 | miss 数 | 正确 DocType **出现过** | 正确 DocType **连出现都没出现** |

### 12.4 🔴 判定：**瓶颈在选单据，不在选字段**

⇒ **换更大的嵌入模型不是解法。** §11 那条 Deferred 的重开条件是「P4 ❌ 才重开」，

它假设「已经知道正确 DocType」，而那正是待解的部分。

### 12.5 与 Spike 07 分歧的一处，机制已查明

Spike 07 上「只索引有数据的 DocType」**加了约 15 个点**；**本站点上它反而降 2.5 个点**
（65.0% → 62.5%）。逐题拆开，机制是干净的：

- **新中 4 条**（库存价值 / 批次管理 / 工单产量 / 总账借方）——**过滤器的收益真实存在，与 Spike 07 同向**
- **丢掉 5 条**——**恰好就是 §1.5 跑之前点名的那 5 条**（`Quotation` / `Purchase Receipt Item` /
  `Job Card` / `Payment Entry` / `Quality Inspection`），它们在 business 档**全部命中**，
  在 live 档因答案 DocType 行数为 0 而**被过滤器排除，全部变成不可能命中**

⇒ **净 −1 条。** 这不是 Spike 07 的结论错了，是**本站点种子数据太薄**：
`live` 过滤器的净收益 = 干扰项减少的增益 − 正确答案被误杀的损失，
而后者由**站点有多少张单据类型真的有数据**决定。

> **对 P2 的直接含义**：`live` 过滤器**不能无条件启用**。要用它，
> 要么站点数据宽度够（真实生产库通常够），要么把「有数据」放宽成
> 「有数据，或被有数据的 DocType 通过 Link 指向」。**后者未实测，不得据此选路（D-16）。**

### 12.6 P0 那个 0% 该怎么读
