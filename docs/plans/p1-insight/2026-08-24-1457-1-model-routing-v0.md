### 1.3 certifi 是一个**未声明**的依赖 —— 这条决定新代码怎么摆

- `pyproject.toml` **没有 `[project] dependencies` 键**（实读全文 32 行）。
- CI 的 `unit-and-contracts` job 只 `pip install pytest`（`.github/workflows/gates.yml:443`），
  `lint` job 只 `pip install ruff==0.14.1`（`:479`）。
- 因此：**任何被 `tests/unit` / `tests/contracts` 传递 import 到的模块都不许在模块级 `import certifi`**，
  否则 CI 当场 ImportError。实验设施今天躲开这一劫，只是因为
  `tests/experiments` **不在任何 CI job 里**。
- D-11 的「环境注记」又逐字要求「**产品代码须显式
  `ssl.create_default_context(cafile=certifi.where())`**」。两者不冲突，但**摆放方式被框死了**：
  证书上下文只能在真正要打网络时构造（惰性 import），不能在模块顶层。

产品侧缺三样，且三样是**同一个结果面**（「解释 Agent 要调模型时，调哪一个、允不允许调」）：

③ 一个在能力不满足时**明确失败**的路由器。

## 2. Goals

1. `agenerp/routing/` 落地：OpenAI 兼容 adapter（transport 可注入、三项 token 分开记、失败不降级）
   + 能力声明 + 路由器，**产品包内零硬编码厂商名**（DashScope 只是一份配置）。
2. 路由器在**所需能力不被目标模型满足时明确失败**，绝不静默换一个模型或静默降级
   （`model-management.md` §12.1 ③ 的逐字要求，本 plan 第一次把它变成可断言的东西）。
3. `python3 -m pytest tests/routing -q` 退 0（WBS §4 P1.1 的验收前半）。
4. 分档表落 `docs/architecture/`（WBS §4 P1.1 的验收后半），**并在同一次改动里修掉 §1.4 那处漂移**。

## 3. Non-Goals

1. **不改 `tools/experiments/p1_entry_gate/**` 的任何一行。** P1.0 已收口，它的 14 份轨迹是判定证据；
   把实验设施改接产品 adapter 会让那次实验不再逐字可复跑。**不是「以后再改」——是本 plan 明确不做**，
   重开事件写在 §9。
2. **不做控制循环**（会话开场、工具编排、强制续跑）。那是 P1.2 / P1.3 / P1.4。
   本 plan 交付的是「被循环调用的东西」，不是循环。
3. **不做前缀缓存与成本上限执行面**（§12.2 / P1.7）。本 plan 只保证 token 三项**可被读出来**，
   不设闸、不计费、不做预算拦截。
4. **不做 embedding / 向量通道**（§12.1 ② 第三行）。`context-and-memory.md` §8.1 的现行结论是
   「结构化导航优先，向量仅作兜底」，P1.0a 已把它列为 out-of-scope 且重开事件未触发。
5. **不选新模型、不翻 D-11。** 默认仍是 `qwen3.6-plus`。翻案要「本项目自己的实测数据」，不是本 plan 的事。
6. **不改 `missions/*.json`、不改 `.github/workflows/**`、不碰 `tests/gates/**`。** 红线 1/2 与 Protected Areas。

## 5. Infrastructure And Config Prereqs

### 5.1 环境变量

| 变量 | 用途 | 有无默认 |
|---|---|---|
| `AGENERP_LLM_BASE_URL` | OpenAI 兼容端点 | **无默认，缺则明确失败** |
| `AGENERP_LLM_API_KEY` | 凭据 | **无默认**，绝不进 git / 日志 / 轨迹 |
| `AGENERP_LLM_MODEL` | 默认模型名 | **无默认** |

**为什么不复用 `DASHSCOPE_*`**：那两个名字把厂商写进了产品配置面，
与 Goals 1「产品包内零硬编码厂商名」直接冲突。`.env` 里 `DASHSCOPE_API_KEY` 已存在且属人管，
本 plan **不改 `.env`、不删旧变量**——实验设施还在用它（Non-Goals 1）。
活站点冒烟时由跑的人显式做一次 `AGENERP_LLM_API_KEY=$DASHSCOPE_API_KEY` 转手，命令原文进 `docs/logs/`。

### 5.2 certifi

按 §1.3：**惰性 import**。`import certifi` 只能出现在真正构造 SSL 上下文的函数体内，
不得出现在任何模块顶层。判据见 Phase 2 的「CI 依赖面反测」。
`pyproject.toml` 本 plan **不加 `dependencies` 键**——加了就要同步 CI 的
`pip install`（`.github/workflows/**` 在红线 2 内，loop 不得动），
结果是「声明了但 CI 没装」，比不声明更坏。这条是 §9 的一条 `Deferred But Adjudicated`。

### 5.3 判定面缺口（照 §1.5 的事实处置，不假装没有）

`tests/routing` 既不在 `missions/p1-insight.json` 的 `commands.test` 里，也不在任何 CI job 里。
**本 plan 的代偿控制有三条，全部在本 plan 权限内**：
① Phase 3 的假实现变异自查（照 P1.0a 的先例，逐个植入、逐个打红、原样还原）；
② 独立关闭审计（`closure-audit-prompt.md`）；
③ 收口时**在 STATE §3 追加一条 needs-human**，把「`tests/routing` 与 `tests/tools` 一并接进
`unit-and-contracts` / `lint`」交给人。**收口时不得声称 CI 已覆盖 `tests/routing`。**

### 5.4 无其它 infra 前置

不需要活站点、不需要 docker、不需要种子数据。
唯一需要网络的是 Phase 3 的一次活端点冒烟，且它 `-m live`，无凭据时 skip 并打印理由。
