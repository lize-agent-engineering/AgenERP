- **5 条负例里「外协」出现 0 次；19 条正例里出现 18 次**（唯一例外 `run-12`）

  **负例 5/5、正例 18/19 = 23/24**；

  （`外协` / `临港` / `科技` / `07` …）；
- 纯长度阈值**做不到**（最好只有负例 5/5 + 正例 13/19）—— 洞不在长度，在内容词。

**⚠️ 第三约束，起草期在收紧口径之后又实测了一次，结论是口径这条路走到头了**：
把 H2 收紧成「**负例三分类逐条精确 + 正例 ≥17/19**」之后，**下面这个两行规则照样通过**——

```python
def judge(a):
    if len(a) < 300: return "truncated"          # run-07 是 179，次短的 run-02 是 539
    return "correct" if "外协" in a else "incomplete"
```

起草期实测：**负例三分类精确 5/5、正例 18/19 ⇒ 通过新口径。**
⚠️ **而且它不是孤例**：把「长度阈值 × 单子串」两维一起扫，
**共 59 个不同子串**能这样通过新口径，且**每一个在任意能把 179 与 539 分开的阈值上都成立**
（`run-07` 179 字符，次短的 `run-02` 539 字符 ⇒ 阈值取 180–539 之间**任意值**都行）。
⚠️ 规则**个数**取决于阈值取多细，是个没有意义的数；**有意义的是那 59 个子串和那段连续的阈值区间**。
⇒ **收紧口径没有、也不可能关掉这个洞** —— 24 条样本、5 条负例、内容词线性可分，
**任何纯结果口径都撑不住「它真的在判断」这个结论**。

## 2. Goals

1. 本仓有一个**判自由文本答案**的判定器（`agenerp/judging/`），它**先跑通那 24 条人工标注**
   ——「跑通」的口径在 §6 H2 起草期写死，不许执行期现编。
2. 判定器的判别力有**反测证明**：`always-correct` / `always-incomplete` / `always-truncated`
   **以及起草期实测出来的那个一行关键词匹配器 `'外协' in answer`**（§1.3），
   在**同一个验收函数**下逐个跑一遍，结果**全部预注册在 §6 H1 / H1c 里**。这条是**离线判据**，不烧 token。
   ⚠️ **口径本身挡不住关键词匹配器，而且收紧也挡不住** —— §1.3 已两次实测：
   收紧后单子串规则被挡下了，**两行规则照样通过**（H1c(b)）。
   ⇒ §6 H2 是**必要条件，不是充分条件**；本 plan 对它的定位就写死在这句话上。
3. 「**判定器不是关键词正则**」由**结构判据**证明，不由实测口径证明（§1.3 的第二约束）：
   **标签必须是模型回包的函数** —— 同一段答案（**取一条含「外协」的**）配两份不同的假回包，
   必须得到两个不同的标签（关键词匹配器与混合短路按构造都过不了这条）；
   且**生成的 `messages` 与该行的 `label` / `reason` 取值无关** ——
   判据是「真行 vs 噪声替换后的同一行 ⇒ `messages` **逐字节相同**」（§6 H7 ②）。
   两条都在 `tests/unit`，零网络。
4. 每一次判定都**记账**（走 P1.7 的 `CallLedger`）且**留痕可复核**：全量一趟的逐条判定结果
   落 `docs/evidence/p1-answer-judge/`，含模型名、prompt 摘要、原始回包 usage。
5. **标注集一个字节不改**：判定结果不写回 `tests/fixtures/p1_entry_gate_labels.jsonl`
   （收口时 `git diff --stat -- tests/fixtures/` 必须无输出）。

### 5.2 采样计划与调用次数上限（**起草期写死，执行期只对账**）

**先把「一轮」和「一次修订」定义死**（上一版这两个词没定义，算术自相矛盾）：

- **一轮 = 一次全量 24 条判定。** 初次跑是**第 1 轮**。

| 用途 | 条数 | 每条判几次 | 调用次数 | 跑几遍 | 小计 |

| 合计 | — | — | — | — | **≤ 72** |

**全程调用上限 = 72 次。** 执行期实际次数由 `CallLedger` 的条数对账；
**超了就停机并在 §12 照实记**，不许悄悄多跑。
⚠️ **72 = 48+18+6，零余量** —— 一次网络重试就会撞上 §5.3 第 6 条。
**这是有意的**：重试也是真花掉的调用，把它算进预算之外等于把账做小。
撞上时的动作是**停机记账**，不是"再给几次" —— 要更多只能由**人**改这个数。

⚠️ **本表没有 token 上限，只有调用次数上限。** 单次判定的 token 量本仓没测过，
