- **Phase 1 · `agenerp` 契约骨架**：新增 `agenerp/__init__.py`、`agenerp/pack.py`、`agenerp/snapshot.py`，
  六个契约面（`normalize` / `export_customizations` / `apply_pack` / `capture` / `diff` / `schema_drift`）
  签名逐字对齐 `tests/gates/` 里的调用处，函数体一律 `raise NotImplementedError` 并指向 roadmap 工作项。
  这让 5 条门禁的红因从 `ModuleNotFoundError` 变成 `NotImplementedError`——与
  `tests/gates/conftest.py:1-8` 已确立的「红在实现不存在，而不是红在名字拼错」约定一致。
  - 关键决定：**扁平 `agenerp/`，不用 `src/` 布局**。CI 的 `gates-l1` job 只 `pip install pytest`、
    直接在 checkout 根目录跑判定器，src 布局会让门禁红在「装没装上」。
  - 机制要说准：扁平布局能被导入**不是**靠 pytest rootdir，而是靠 `python3 -m pytest` 把 CWD 插进
    `sys.path`（`tools/gates/check_expected_red.py:35` 正是 `[sys.executable, "-m", "pytest"]`）。
    为让裸 `pytest` 也成立，`pyproject.toml` 加了 `[tool.pytest.ini_options].pythonpath = ["."]`。
  - `pyproject.toml` 另加 `[build-system]`（setuptools）、`[tool.setuptools.packages.find]`（只收 `agenerp*`）、
    `[tool.ruff]`（line-length 100 / py312 / `exclude = ["tests/gates"]`）。**不加 mypy 配置**——本机没装，
    写进去就是新占位符。`exclude` 是 lint 作用域界定，不是放松门禁：判定器是
    `check_expected_red.py`，与 ruff 无关；排它是因为唯一的 `E741` offender 在红线 1 内不可改。
