# 作废轨迹：`--max-tokens 24000`（操作失误）

这 12 份**全部作废，不得用于任何结论**。

**原因**：跑的人（人侧会话）把 `--max-tokens` 填成 24000，而第一轮用的是
**200000**，差了近十倍。新档位模型每轮工具调用更多、prompt 累积更快，
12 次里 **11 次被 token 上限掐断**（实际用量 24,788 – 34,652），
最终答案为空或截断。

**这不是模型答错，是实验被掐断。** 留档不删，因为：
① 它是「判据不许只验看起来像不像」的又一实例 —— 初判显示「全 0/12」，
   若不追查会得出「百炼最高档也过不了这道题」这个完全错误的结论；
② 实验代码**正确地**把它们标了 `invalid`，是判定环节没排除 —— 记下来，
   下次先查 `invalid` 再判分。

重跑见上级目录，`--max-tokens 200000`（与第一轮逐字相同）。
