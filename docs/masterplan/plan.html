阶段阶梯 没有日期——工期由门禁决定，不由日历决定

空心 = 人工，不由循环推 实心 = 循环推进，高度 = 该阶段先红着的门禁测试数 菱形 = 阶段入口关口实验，不过不许进下一阶段

故意没画甘特：这套计划里没有任何一条日期是真的，工期取决于门禁什么时候转绿。画出日期条等于凭空造数。

循环 唯一一处上色的地方，就是判定权所在的地方

上游那套循环里，「测试过了没有」自始至终由被考核者自我汇报。本项目补的就是最右边那个框——它谎报 pass，下一步立刻被独立复跑打脸。

LoopX 试点，严格分层
补配额感知续跑 + 监督态确定性维护。LoopX 管 WBS 项级跨会话状态，mission-driver 管 mission 内执行状态，写回单向且不经 AI。
退出判据事先写死：Day 0 内 2 小时跑不通闭环，当场退回 STATE.md 手工纪律。

停机 宁可停，不带病狂奔

触发第一反应禁止的反应
同一 plan 连败 3 轮走 CP6：先原样复跑那条命令直接改测试让它过
diff 触及 tests/gates/**立即停机，查是谁改的「这次是善意修改」
成本超阈值停机，算清钱花在哪提高阈值继续跑
CI 连红 2 轮停机本地绿就当过了

处置走五步：停机保留现场 → 写 needs-human → 先原样复跑失败命令 → 修 WBS 行 / 修实现 / 重开决策（须人拍板）→ 标 resolved 并重启。第三步是关键：不复现就分析，等于让模型在想象的失败上工作。
