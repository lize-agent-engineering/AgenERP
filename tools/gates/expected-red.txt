#
# CI 的 `gates` job 用它把「故意的红」和「真的坏了」区分开：
#   · 名单内的测试红   → 正常，CI 绿
#   · 名单内的测试却绿 → **失败**（名单过期了，实现已到位就该把它从名单里划掉）
#   · 名单外的测试红   → **失败**（真的坏了）
#
# 棘轮方向：这个名单**只能变短**。变长 = 有人把一个真失败塞进来充当「预期」，
# CI 的 `expected-red-ratchet` job 会拦下，除非提交信息里带人工批准：
#   Gates-Change-Approved-By: <姓名>
